## 演示要点（本地账号登录后）

1. **首页 Life Studio**：四个统计卡片（记忆/故事/照片/音视频）都可点击进入对应管理页；每日问题、最近动态、快捷创作。
2. **我的记忆**：20 条跨越 1953–2023 的人生记忆；支持全字段编辑、搜索筛选、拖拽多文件上传、回收站恢复。
3. **AI 故事**：版本历史、A/B 对比、一键切换 7 种叙事风格重新生成。
4. **语音录制**：真实 Qwen3-ASR 转写；5 段 TTS 口述录音可在媒体库播放。
5. **媒体库**：照片/音频/视频分类、拖拽上传（含分片）、caption 编辑、移动到其它记忆、点击弹层预览。
6. **人生图谱**：5 个人生阶段、4 个里程碑、7 位人物关系。
7. **家庭空间**：林氏家族，成员角色与邀请管理。
8. **回忆录**：6 章节、PDF/Markdown/JSON 导出、可撤销二维码、封面封底预览。
9. **数字传承**：显式授权策略、事件时间线（不自动交付数据）。
10. **全局搜索 / 设置 / 活动审计**：顶栏搜索、改密、会话、数据导出、分片上传。

## 生产/ Pages 说明

GitHub Pages 只能托管静态前端，无法运行 FastAPI 后端。 Pages 部署时需配置后端可达地址：
- 在仓库 Settings → Variables → Actions 添加 `VITE_API_BASE`，值为已部署后端 API 的完整地址（如 `https://api.example.com/api`）。
- 若不配置，前端会请求站点自身的 `/api`，Pages 环境下无后端，登录会失败。
- 后端可用 `docker compose up -d` 部署（见 `docs/DEPLOYMENT.md`）。
