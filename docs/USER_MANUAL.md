# Memoir 用户使用手册

## 登录 / 注册
首次使用点击「立即注册」，填写用户名、邮箱、密码（至少 8 位），注册后自动登录。JWT 凭证保存在本地，支持刷新与退出撤销。

## 首页 · Life Studio
展示记忆总量、故事数、照片/音视频数、每日记忆问题、最近记忆、最近故事、人生里程碑。点击问题可直接进入 AI 访谈。

## 我的记忆 · Memory Vault
- 填写标题、发生日期与原始内容，保存到记忆库。
- 支持编辑（软删除：删除后进入回收站，原数据仍保留）。
- 系统会自动从记忆中抽取时间、人物、地点、情感等实体，并建立可检索的私人记忆库。
- **你写的原始内容永远不会被 AI 覆盖。**

## AI 故事 · Story Studio
1. **故事生成**：选择一段记忆 → 选叙事风格（第一人称/第三人称/逐字稿/文学/精简/纪实）→ 生成。可人工编辑，每次编辑生成新版本，历史版本可恢复。生成过程记录模型与 Prompt 版本。
2. **AI 人生访谈**：选主题 → 逐轮回答 → AI 根据你的回答动态追问 → 说「就这些」结束 → 生成故事初稿。不强迫回答敏感问题。
3. **我的故事**：查看全部故事与状态。

## 语音录制 · Voice Studio
点击录音 → 说出回忆 → 停止 → 点击「上传并转录」→ 查看逐字稿（可修正）→ 生成故事。
- 需要麦克风权限；浏览器录音需 HTTPS 或 localhost。
- 最长 30 分钟。
- **原始录音永久保留**，普通协作者不能删除。
- 默认 Mock ASR 仅返回占位逐字稿；配置真实 ASR 后才返回真实转录文本。

## 人生图谱 · Life Graph
展示从记忆与访谈中抽取的人物、地点、事件关系与人生阶段（基础视图，持续完善中）。

## 家庭空间 · Family Circle
创建家庭 → 邀请家人（邮箱 + 角色：讲述者/协作者/只读/管理员）→ 成员接受邀请。权限在服务端强制校验，前端隐藏按钮不是安全边界。

## 回忆录 · Legacy Book
新建回忆录 → 添加章节 → 导出 PDF / Markdown / JSON → 为故事生成二维码。
- 二维码使用稳定不可预测的令牌，可随时撤销；公开故事页仍会检查授权范围。
- 二维码不暴露任何内部存储路径。

## 数字传承 · Digital Legacy
添加传承联系人 → 创建访问策略草稿 → 显式授权 → 可随时撤销。
- **联系人不会自动获得你的全部记忆**：必须显式授权 + 身份核验 + 人工审核。
- 不会因长期未登录自动交付数据。

## 老年简洁模式
右上角点击「Aa 简洁模式」，切换大字号、大按钮、简化界面。
