## 生产/ Pages 说明

GitHub Pages 只能托管静态前端，无法运行 FastAPI 后端。 Pages 部署时需配置后端可达地址：
- 在仓库 Settings → Variables → Actions 添加 `VITE_API_BASE`，值为已部署后端 API 的完整地址（如 `https://api.example.com/api`）。
- 若不配置，前端会请求站点自身的 `/api`，Pages 环境下无后端，登录会失败。
- 后端可用 `docker compose up -d` 部署（见 `docs/DEPLOYMENT.md`）。
